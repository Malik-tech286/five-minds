# خمس عقول — نسخة محسّنة

## الملفات
- `index.html`: واجهة الموقع والتطبيق.
- `manifest.json`: تعريف تطبيق الويب القابل للتثبيت (PWA).
- `sw.js`: تخزين ملفات الواجهة مؤقتًا للعمل على نحو أفضل عند ضعف الاتصال.
- `icon.svg`: أيقونة التطبيق.

## النشر على GitHub Pages
ارفع الملفات الأربعة إلى نفس مجلد `index.html` في المستودع. فعّل GitHub Pages من إعدادات المستودع. التثبيت يتطلب HTTPS؛ بعد النشر افتح الموقع من Chrome/Edge ثم اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» حسب الجهاز.

## المفاتيح والخصوصية
المفاتيح محفوظة في `localStorage` باستمرار على المتصفح والجهاز حتى يمسحها المستخدم. هذا لا يزامنها بين الأجهزة ولا ينقلها للمستخدمين الآخرين. لا تستخدم حفظ المفاتيح على جهاز عام أو مشترك. المفاتيح تُرسل مباشرة إلى مزوّد API الذي اختاره المستخدم. كل مزوّد قد يفرض رسومًا أو حدود استخدام.

## APK
هذه الملفات تجهّز نسخة PWA قابلة للتثبيت؛ لا تنتج APK بحد ذاتها. لإنشاء APK حقيقي، افتح الموقع المنشور داخل مشروع Android باستخدام Trusted Web Activity (Bubblewrap) أو Capacitor، ثم ابنِ APK ووقّعه. لا تضع أي مفاتيح API خاصة بك داخل APK أو المستودع.

## ملاحظات
- لا يوجد backend أو نظام حسابات في هذه النسخة.
- تخزين المفاتيح الدائم اختيار مقصود حسب طلب صاحب المشروع، لكنه أقل أمانًا من تخزينها في الجلسة فقط.
- يجب اختبار كل مزوّد وموديل بمفتاح صالح؛ توافر النماذج وشروط API تتغير بمرور الوقت.
